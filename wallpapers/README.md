# Wallpapers

Coloca aqui as tuas imagens (`.jpg`, `.png`, `.bmp`) e o aplicativo usa-as
todas:

* o **MODO JOGO** aplica a imagem escolhida
* a pagina **AJUSTES** mostra as duas primeiras para escolher
* o **seletor de wallpaper** (botao "Escolher outro ficheiro...") deixa-te
  escolher qualquer imagem do PC

Sem imagens nesta pasta o aplicativo funciona na mesma: usa o wallpaper
actual do Windows e nao muda nada.
